# Alcance del bootstrap

La especificación aprobada vive en **YtuFit — v1.3 Design System & App Socio** y el producto fue definido hasta v1.6. En esta entrega no se reproducen ni reinterpretan pantallas: se prepara la arquitectura para web, mobile y Supabase.

## Dominios MVP reservados

Identity, Gyms, Members, Memberships, Attendance, Training, Progress, Streaks, Loyalty, Notifications y Analytics.

## Fuera de alcance

Pagos integrados, checkout/store completo, promociones avanzadas, chat, nutrición, social feed, IA y multi-sucursal avanzada.

Antes de implementar UI o flujos, contrastar el comportamiento con Figma y documentar cualquier desviación mediante ADR.
